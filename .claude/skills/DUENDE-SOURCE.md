# Vendored Duende skills and agents

The Duende skill folders in `.claude/skills/` and the agents in `.claude/agents/`
(`identity-server-specialist.md`, `oauth-oidc-specialist.md`) are copied unchanged from
[DuendeSoftware/duende-skills](https://github.com/DuendeSoftware/duende-skills),
commit `91e793d` (2026-07-22), plugin version 0.1.0. License: MIT, see `DUENDE-LICENSE`.

To update: pull the upstream repo and copy `skills/*` and `agents/*.md` over these files again,
then update the commit hash above. Do not edit the vendored files in place; local changes
would be lost on the next update.
